# 双模式改造清单（国内版 / 国际版）

## 1. 模式参数传递

- 前端：`localStorage.travelone.mode` 保存 `cn` / `global`，`API.mode` 作为全局默认值，所有 `/api/*` 请求在查询串追加 `mode`。
- 后端：`web_api._str(query, "mode")` 读取，默认 `cn`；仅下列接口分流：
  - `/api/meta`、`/api/attractions`、`/api/attractions/<key>`、`/api/hotels`、`/api/hotels/<id>`、`/api/search`、`/api/compare`、`/api/transport`、`/api/sources`、`/api/coverage`、`/api/config`、`/api/map/guide`。

## 2. 快照作用域命名

- 国内沿用现有城市名（如 `北京`）。
- 国际统一前缀：`intl::<City>`（如 `intl::Paris`），避免与国内同名城市冲突；`cache_store` 的“同城只留最新一份”规则按该 scope 生效。

## 3. 新增模块

| 模块 | 职责 |
| --- | --- |
| `collectors/wikidata_places.py` | QLever 查询景点/酒店/地铁；`LANDMARK_INFO` 白名单按 QID 直取标志性景点；`search_landmarks` 支持中文名、繁体字与英文别名 |
| `services/intl.py` | 国际版数据层：`harvest` / `search` / `detail` / `metros` / `nearby_hotels` / `cities` / `stats`，读写 `intl::` 快照；`transport` 提供机票分段、区域铁路与自驾成本模型 |
| `services/intl_warmup.py` | 启动即后台按城市轮扫国际景点/酒店/地铁，状态经 `/api/warmup?mode=global` 与数据源面板展示 |
| `static/js/map.js`（MapLibreAdapter） | 国际版用 MapLibre GL JS 渲染 OSM 栅格瓦片（本地 `vendor/`，免 Key），带 ODbL 署名；瓦片不可达时保留标记与路线并提示 |

## 4. 改动模块

- `services/live.py`：不改内部实现，仅由 `web_api` 按模式选择调用方。
- `web_api.py`：模式分流 + `api_meta` 国际城市清单 + `api_transport` 国际口径（机票分段 / 铁路 / 自驾，无实时报价源，全部标估算）。
- `static/js/api.js`：请求统一带 `mode`。
- `static/js/app.js`：模式切换、切换时的差异声明、城市列表与文案重渲染；国际模式隐藏国内专属项（12306/油价）。
- `static/index.html`：顶栏加入“国内 / 国际”分段控件。
- `static/css/app.css`：模式徽标与声明弹层样式。
- `core/config.py`：不再需要 Google 地图 Key；国际版底图走本地 MapLibre + OSM 瓦片。
- `docs/平台数据源.md`：补国际源与 ODbL 署名说明。

## 5. 国际版差异项（切换声明要覆盖）

1. 数据源：百度地图 → Wikidata（CC0）。Overpass/Nominatim 在本机网络不可达，已移除该链路；底图瓦片仍为 OSM，需署名。
2. 覆盖范围：国内行政区轮扫 → 国际城市清单 + 按需抓取。
3. 地图服务：百度地图 → MapLibre GL JS + OpenStreetMap 瓦片（免 Key，显示 © OpenStreetMap contributors）；瓦片不可达时保留标记与路线并提示。
4. 价格与评分：国际源不含门票价、房晚价与评分，相关字段显示空缺。
5. 估算口径：机票按航距分段 × 航线/枢纽系数；同区域 1600 km 内给铁路估算；自驾按当地油价 × 固定参考汇率；均标注估算，无实时报价源。
