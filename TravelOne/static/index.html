Transport & fuel sources

Fuel price tableLive

Provincial 92#/95#/0# pump prices are read from a public price table and cached for six hours; they feed the self-drive cost.

China Railway (12306)Timetable

Train numbers and origin/destination are read from the public 12306 timetable files, so each corridor lists its real trains. The ticket API returns an encrypted payload, so fares stay estimates from the published tariff.

Flight listsSigned API

Airline and OTA flight lists require a signed client session; TravelOne shows time and price ranges marked as estimates and never presents them as live quotes.

BookingNot provided

There is no purchase or ticketing channel in this app: it only synchronises and compares published prices and travel time.

Platform sources

QunarLive price

Channel room rates come back through the built-in Baidu Maps aggregation; each quote keeps its own source label and fetch time.

CtripRatings only

Public pages expose hotel names, star ratings, guest scores and review counts. Room prices require an authenticated session, so no anonymous price is shown.

Trip.com (Ctrip Group)No anonymous feed

Featured lists carry prices, but there is no stable per-hotel anonymous endpoint; the app does not guess or mirror those numbers.

TongchengBlocked

The H5 list API (/tapi/*) requires an h5sign signature; anonymous requests are rejected, so no price or rating is claimed.

MeituanBlocked

Hotel search returns 403 without an mtgsig-signed session; the app reports the platform as unavailable instead of inventing a quote.

About

This project ships no database and no bundled dataset: attractions, hotels, tickets and rates are crawled from Baidu Maps at runtime. data/cache holds only the last fetch per area as JSON and can be cleared in one click.
Type at least two characters; results span every tracked city.

Enable the real Baidu basemap and live routes

Everything works without an AK: lists, price comparison, the offline schematic map, nearest-first sorting and locally estimated routes. With an AK the map becomes the real basemap, browser geolocation is available, and routes are computed live by Baidu.AKs are stored only on this machine.

1
Open Baidu LBS Open Platform and complete identity verification
2
Console → App Management → My Apps → Create App. Choose type Browser and enable JavaScript API
3
Set the Referer whitelist to * (or add 127.0.0.1 and localhost too). Replace it with your domain in production.
4
Copy the 24-character AK and paste it into Browser-side AK below
5
For real driving/transit routes and address lookup, create a second Server app with IP whitelist 127.0.0.1 and paste its AK into Server AK
6
Save, click Test AK, and it takes effect immediately; the map header shows Baidu Maps
No AK configured; using the offline schematic map
Security: the field accepts paste only and blocks copy and right-click. The value is encrypted on this machine before saving; only ciphertext is stored.
AKs are stored only on this machine in data/runtime_config.json (encrypted) and never uploaded.

Open this app through the local service
